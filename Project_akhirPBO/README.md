# Update Versi 2.0

Pada versi 2.0 ditambahkan fitur Member VIP sebagai subclass dari Pembeli. Member VIP memiliki atribut poin reward dan menerapkan polymorphism melalui override method beriUlasan().

Selain itu ditambahkan fitur filter Member VIP pada daftar ulasan, sehingga pengguna dapat melihat ulasan yang dibuat oleh Member VIP saja.
